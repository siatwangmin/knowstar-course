# 学员入口｜从空目录做出知错星

你只需要会复制文字、打开网页和检查结果。课程只有**一个工程目录**，每学完一阶段就在原工程上继续，不重新创建项目。每一步让 TraeWork 做技术操作；你只回答产品问题、保管自己的服务配置，并亲自试用页面。

## 按这个顺序走

| 顺序 | 打开 | 你要做什么 | 过关后看到什么 |
| --- | --- | --- | --- |
| 1 | [准备环境](01-环境.md) | 安装 Docker Desktop，导入环境 Skill，启动空白工程；准备自己账号的 CloudBase 与硅基流动配置 | 浏览器出现“环境已就绪”，Web 和占位 APK 编译成功；有不含密钥值的配置清单 |
| 2 | [认识工程](02-工程模板.md) | 打开自动生成的 `knowstar-learning`，导入课程 Skill | TraeWork 能读工程约束，你不用选框架 |
| 3 | [设计](03-需求与原型.md) | 与 Gemini 对话完成 `PRD.md`，再从 Canvas 导出 HTML 原型 | 两个自己的文件，原型能演示完整操作 |
| 4 | [V1 本地网页](04-V1-本地网页.md) | 对 TraeWork 说“我要做本地网页” | 数据在本机浏览器中保存，刷新不丢 |
| 5 | [V2 云端](05-V2-云端.md)与[上线案例](09-网页上线案例.md) | 对 TraeWork 说“我要部署云端”；创建课程演示用户，接入动态数据 | Pages 发布配置就绪；两台设备登录同一用户后同步数据 |
| 6 | [V3 安卓](06-V3-安卓.md) | 对 TraeWork 说“我要安卓版本” | 同一工程编出 APK；安卓与网页登录同一用户后同步数据 |
| 7 | [V4 AI](07-V4-AI.md) | 对 TraeWork 说“我要加 AI 能力” | 硅基流动识题、诊断等可用，密钥不出现在网页 |

**只进入下一阶段一次。** 每章末尾有“过关检查”，没有通过时把报错交给 TraeWork 修复，不要跳过。环境阶段先准备自己的腾讯云和硅基流动账号并了解配置位置；V1 可先本地开发，V2 要用自己的 CloudBase 环境，V3 需要安卓设备，V4 才将自己保管的硅基流动 API Key 填入云函数服务端环境。

## 你的工作目录

环境 Skill 在你选的空目录下创建 `compose.yaml` 与 `knowstar-learning/`。设计阶段只需将自己的 `docs/design/PRD.md` 和 Canvas 导出的 HTML 放进工程；代码随后在同一工程开发。每阶段记录 `docs/progress/`：提示词、脱敏截图、测试结果、遇到的问题。教师资料包不提供 API Key、演示用户密码或管理密钥；你也不要把这些值发给 TraeWork 或上传到 GitHub。

## 两个 Skill

- [环境 Skill ZIP](../knowstar-env-skill.zip)：只在第 1 步用一次；负责 Docker 与空白工程。
- [课程 Skill ZIP](../knowstar-course-skill.zip)：在第 2 步导入；你说“本地网页/云端/安卓/AI”时自动套用课程技术路线。它不能代替真实账号开通、页面试用和真机操作。

遇到不认识的词，先看[一句话词典](08-词典与求助.md)。教师参考答案不在学员资料包中。
