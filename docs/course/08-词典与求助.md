# 一句话词典与求助方式

| 名词 | 你只需理解 |
| --- | --- |
| 镜像 | 教师打包好的工具箱，里面已有开发和安卓编译工具。 |
| 容器 | 工具箱运行起来后的工作空间。你的代码仍在自己的电脑目录里。 |
| 工程模板 | 可运行但没有产品功能的起点。 |
| PRD | 写清“为谁做、做什么、怎样算成功”。 |
| Canvas | 可点击的设计原型，后续页面照它做。 |
| GitHub Pages | 把网页文件发布到公网的地址，不保存个人错题。 |
| CloudBase | 负责共享演示数据、图片与云端程序。 |
| APK | 安卓手机可安装的文件。 |
| API Key | 调用模型的秘密凭证，只能放服务端。 |

遇到问题，把下面一段发给 TraeWork：

```text
我正在按知错星课程第 __ 章第 __ 步操作。预期是 __，实际看到 __。这是完整报错或截图：__。请先检查当前目录和实际命令结果，解释原因并修复；不要跳到下一阶段，不要让我自己猜命令。修复后重跑本步验收并报告结果。
```

不要把密码、API Key、个人错题图片粘到聊天或公开仓库。
