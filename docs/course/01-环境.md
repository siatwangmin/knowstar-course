# 1｜准备环境

**你现在只有一台电脑和空目录。** 不需要下载 npm 包、Tailwind、Java 或 Android SDK；这些已经在统一镜像里。需要先能运行 Docker Desktop。

1. 在 Windows 10/11 打开 [Docker Desktop 官方安装页](https://docs.docker.com/desktop/setup/install/windows-install/)，按你的系统要求安装、重启并启动。保持 **Linux containers**。默认安装常用 WSL 2；符合条件的电脑也可用 Hyper-V。
2. 在 Windows PowerShell 输入 `docker version` 和 `docker compose version`。前一条要看到 `Server`，后一条要看到版本号。做不到时先把画面交给 TraeWork，不继续拉镜像。
3. 在 TraeWork 的**本地 Code 任务**导入[环境 Skill](../knowstar-env-skill.zip)，选一个空目录，发送：

```text
使用 knowstar-classroom-env Skill。请在我选的空目录拉取课程固定镜像、启动容器，验证网页与安卓编译环境。每一步告诉我正在做什么、完成后我该看到什么；失败就停在当前步骤修复。不要索取 ACR 密码。
```

4. 等它报告通过后，在浏览器打开 `http://localhost:5187/`。应看到“环境已就绪”。目录中应有 `compose.yaml`、`knowstar-learning/package.json`、`tailwind.config.js`、`postcss.config.js`。Skill 还应报告 Tailwind 3/PostCSS/Autoprefixer 已从镜像本地提供、Web 构建成功、占位 APK 的路径和摘要。
5. **准备你自己的云服务配置**。按[CloudBase 开通步骤](10-开通CloudBase.md)创建自己的环境，取得 EnvId 和浏览器 Publishable Key，并在自己的环境创建课程演示用户。再到[硅基流动控制台](https://cloud.siliconflow.cn/)用自己的账号创建 API Key，自行安全保管。此时还没有云函数，只需准备 Key；到 V4 部署云函数时，你亲自在 CloudBase 控制台将它填入函数的服务端环境变量 `SILICONFLOW_API_KEY`。V1 不调用这些服务，可以先完成本地开发，但进入 V2/V4 前分别核对配置。

| 配置 | 学员填写的位置 | 此阶段的预期结果 |
| --- | --- | --- |
| CloudBase EnvId、Publishable Key | V2 时填入自己工程被 Git 忽略的 `.env.local`；它们是浏览器公开配置 | 已在自己的控制台找到，不使用教师截图里的值 |
| 课程演示用户密码 | V2/V3/V4 时仅在网页或 APK 登录框手动输入 | 自己保管密码，工程和资料包中没有预置账号密码 |
| 硅基流动 API Key | V4 时仅在自己 CloudBase 云函数的服务端环境变量中填写 | 已创建并安全保存；TraeWork 只需知道“已配置”，不读取值 |
| 腾讯云管理密钥等管理凭据 | 不进入课程工程；CloudBase 接入按你自己的账号授权 | 不应出现在学员资料包、镜像、Git 或浏览器产物中 |

把下面这段发给 TraeWork，**只让它检查配置项，不粘贴任何密钥或密码**：

```text
请按知错星课程环境 Skill 帮我检查个人服务配置准备情况：CloudBase 环境是否由我自己开通、是否能找到 EnvId 和浏览器 Publishable Key、课程演示用户是否需要创建、硅基流动 API Key 是否已由我自行申请。现在只报告每项“已准备/待准备”和下一步填写位置；不要索取、读取、打印或保存 API Key、密码、腾讯云管理密钥。V4 云函数尚未建立时，不要把 Key 写进项目、Docker 镜像或任何 VITE_* 变量。
```

**预期结果**：你有自己的配置准备清单；TraeWork 的回答没有任何密钥值。教师发放的文档、Skill 和示例文件只包含变量名与空白占位符，不提供可复用的 API Key。

**过关检查**：Docker Server 可用；容器显示 healthy；页面可打开；Tailwind 本地构建配置存在；Web 构建和占位 APK 编译通过；个人云服务配置状态已记录且没有泄露密钥。占位 APK 只证明工具链可用，尚不是你的产品。若 TraeWork 无法操作本机 Docker，照 Skill 给出的 PowerShell 命令在宿主机执行，并把输出贴回 TraeWork。

镜像的固定版本和离线包在[发布清单](../releases/manifest.md)。下一步进入[认识工程](02-工程模板.md)。
