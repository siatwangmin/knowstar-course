# 4｜V1：做一个本地网页

现在你只需说“我要做本地网页”。先前设计的 `docs/design/PRD.md` 和 Canvas 导出的可运行 HTML 应在 `docs/design/`。HTML 文件名由学员自己决定，例如 `know-star.html`。**本阶段不需要云账号、安卓设备或 AI Key。**

## 第一次对 TraeWork 说

```text
使用 knowstar-course Skill，我要开发 V1 本地网页。先找到并读取我在 docs/design/ 中的 PRD.md 和 Canvas 导出的 HTML（例如 know-star.html），再检查当前代码；如果缺文件，明确告诉我缺哪份并指导我回 Gemini 补齐，不要要求 spec.md 或 canvas-handoff.md，也不要自行猜设计。技术路线从课程 Skill 和本工程 AGENTS.md 获取；产品规则看 PRD，视觉和交互看实际 HTML。先核对项目已内置 Tailwind 3、PostCSS、Autoprefixer，CSS 有 @tailwind 指令，构建产物确实包含原型使用的 flex/grid/bg/text/gap 等工具样式；不要从 CDN 加载 Tailwind，也不要运行 npm install。若镜像缺依赖，报告环境版本问题。然后给我不超过四步的实现顺序，每步说明可见结果并逐步实现。将原型 HTML 的布局、配色、字号、间距、状态和交互移植到生产 React，不重新设计。保持单页怪兽卡、周末试炼、添加弹窗，不做五 Tab；刷新后本地数据仍在。用相同视口和相同示例数据分别截图原型与 localhost:5187，逐项修正明显差异。每一步验收后再继续。
```

## 跟着四个小成果走

| 小成果 | 你对 TraeWork 说 | 你亲眼验收 |
| --- | --- | --- |
| 1 数据规则 | “先实现题目、学科、错因、LV1–LV3 和周末试炼的规则，给我看最简单的自动检查结果。” | 升级不会越级；LV3 不进待复习题；测试通过。 |
| 2 录题 | “按 Canvas 做录题弹窗、选图和画板，保存到本机浏览器。请给我打开网页的地址。” | 录一题、画一笔、刷新后内容仍在；失败时输入还在。 |
| 3 怪兽卡 | “按 Canvas 做单页卡片、学科筛选、翻牌、错因、升级、礼花与声音。” | 亲自翻卡、筛选、升级；小屏幕不遮住按钮。 |
| 4 周末试炼 | “实现 LV1/LV2 选题、A4 打印、空数据提示；运行构建和真实浏览器检查。” | 打印预览是 A4；没有 LV3 题；空列表不崩溃。 |

开始写业务代码前，请 TraeWork 报告它读取的原型 HTML 路径，并确认 Tailwind 的本地构建链路：`tailwind.config.js` 扫描 `src/`，`postcss.config.js` 启用 Tailwind/Autoprefixer，`src/style.css` 包含三条 `@tailwind` 指令。仅有 JSX 上的工具类名或 `npm run build` 成功不代表样式生效；应检查构建 CSS 中确实出现页面使用的工具类。统一镜像已预装这些依赖，学员不执行安装命令。

在项目目录保持容器运行；TraeWork 在容器里执行 `npm run build`、测试和浏览器检查。你在 `http://localhost:5187/` 体验。原型的 `file://` 页面与 `localhost` 的浏览器存储互不共享；对照截图前，两边都应进入同一种空状态，或手工录入相同的示例题。桌面和窄屏各对照一次页面结构、卡片、弹窗与试炼状态。每次改完让它报告：改了什么、实际跑了什么、哪项没测到。不要接受“代码看起来正确”或只看 CSS 文件大小作为通过。

**过关检查**：`PRD.md` 与 Canvas HTML 均已读取；本地 Tailwind 样式编译生效；录题→画图→保存→刷新→翻卡→升级→A4 试炼全通；断网时本地操作仍可做；同状态的桌面/窄屏截图与 Canvas 对照无明显结构或视觉偏差。将截图和结果写到 `docs/progress/V1.md`。再进入[V2](05-V2-云端.md)。
